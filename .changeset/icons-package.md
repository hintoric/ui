New package: `@hintoric/icons` ships hintoric's icons and spot illustrations as React components. Each icon renders inline as SVG and switches between its light and dark variant with `data-color-scheme` on `<html>`, which `ColorSchemeProvider` from `@hintoric/ui` sets. Pin a variant with `mode="light"` or `mode="dark"`, name it for screen readers with `title`, and find its CDN URLs on `Icon.cdn`. The `icons` export lists every icon, for galleries and pickers.
